# TheCellCoded DNA Sequence Analyzer

## About the Project

TheCellCoded DNA Sequence Analyzer is a python built project that is explore how computer science ties into genetic
algorithms. DNA contains instructions on characterists and traits that we have, and this project demonstrates how programming can help us understand these sequences.
    Using python, I developed a program that validates DNA sequences, determines the number of each nuecleotide,
the percentage of the G and C nueclotides, and a comparison to a different strand to determine if any substitutions occured.
    This project is part of TheCellCoded, my initiative focused on exploring the intersection of computer science and biology. Through this project, I aim to develop my programming skills while learning more about the applications of bioinformatics.

## Features

1) DNA Sequence Validation: Checks whether an inputted DNA sequence contains only valid nucleotides (A, T, C, and G).

2) Nucleotide Counting: Counts the number of adenine (A), thymine (T), cytosine (C), and guanine (G) nucleotides in a DNA sequence.

3) GC Content Calculation: Calculates the percentage of nucleotides that are guanine (G) or cytosine (C) within a DNA sequence.

4) Complementary DNA Generation: Generates the complementary DNA strand using base-pairing rules (A–T and C–G).

5) Mutation Detection: Compares two DNA sequences of equal length and identifies the indices where their nucleotides differ(subsitutions)

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download the project files from this GitHub repository.
3. Open the project folder in Visual Studio Code or another code editor.
4. Open the terminal and run:
```bash
python3 dna_analyzer.py
```
5. Enter a valid DNA sequence containing only A, T, C, and G.
6. The program will display the nucleotide counts, GC content, and complementary DNA strand.
7. Enter a second DNA sequence of the same length to compare the two sequences and identify potential mutations.
